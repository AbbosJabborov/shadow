# Shadow Index

A regional shadow economy monitoring platform for Uzbekistan — built with React, Vite, Tailwind CSS, and [shadcn/ui](https://ui.shadcn.com).

Tracks a composite shadow economy index across all 14 regions of Uzbekistan, with a registry of monitored MCHJ (LLC) businesses and an industry-level breakdown per region.

This is a two-part project:

- **`/`** — the frontend (this root folder)
- **[`backend/`](backend)** — a separate Node/Express API that generates AI risk reports via Gemini

## Features

- **Dashboard** — national index, regional ranking, and a shade-coded chart of shadow index by region
- **Region detail** — per-region index broken down by industry
- **Business registry** — searchable, filterable, paginated list of monitored businesses
- **Business detail** — AI-assisted risk analysis (simulated) with flagged reasons, plus a **Download PDF Report** button that calls the backend to generate a full MIMIC-based report via Gemini and renders it client-side to a downloadable PDF

Most data is fictional/mock, generated for demonstration purposes — figures are not real economic statistics. The "Calculate with AI" score on the business page ([`src/lib/mock-ai.js`](src/lib/mock-ai.js)) is simulated client-side. The **downloadable PDF report** is genuinely generated by Gemini — see [`backend/README.md`](backend/README.md) for how.

## Getting started

Frontend:

```bash
npm install
npm run dev
```

Backend (required for the "Download PDF Report" button — see [`backend/README.md`](backend/README.md) for full setup):

```bash
cd backend
npm install
npm run dev
```

## Tech stack

**Frontend:** React 19, Vite, Tailwind CSS v4, shadcn/ui (base-ui primitives), React Router, Recharts, jsPDF.
**Backend:** Node.js, Express, `@google/genai` (Gemini).
